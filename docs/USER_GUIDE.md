# คู่มือ TownTrack

## เริ่มต้น
ผู้ดูแลเข้าสู่ระบบ เปลี่ยนรหัสผ่านเริ่มต้น ตั้งชื่อเทศบาล หน่วยงาน บัญชีบุคลากร และประเภทปัญหา ประชาชนสมัครบัญชีท้องถิ่นได้เอง ส่วน LINE จะปรากฏเมื่อกำหนดค่าแล้ว

## ประชาชน
1. เลือก แจ้งปัญหา เลือกประเภท กรอกหัวข้อ รายละเอียด และสถานที่
2. ใช้ GPS ปักหมุดเอง หรือกรอกที่อยู่หากไม่ใช้ตำแหน่ง
3. ถ้ามีพิกัด กดค้นหาปัญหาใกล้เคียง 100 เมตร หากเป็นเรื่องเดียวกันกดติดตาม หรือส่งเรื่องใหม่ได้
4. แนบ PNG/JPEG/PDF ไม่เกิน 10 MB ต่อไฟล์ และส่งคำร้อง
5. ติดตามจากคำร้องของฉัน / เรื่องที่ติดตาม / การแจ้งเตือน
6. แนบหลักฐานเพิ่มได้ขณะยังรอรับเรื่อง หากอัปโหลดไม่สำเร็จแต่บันทึกคำร้องแล้ว ให้เปิดรายละเอียดเพื่อแนบซ้ำ ไม่ต้องสร้างคำร้องใหม่

## เจ้าหน้าที่
1. เปิดคำร้องในหน่วยงานตน ตรวจแล้วรับเรื่องพร้อมเลือกหัวหน้า หรือปฏิเสธพร้อมเหตุผล
2. ถ้ามีคำขอทรัพยากร ตรวจฉบับล่าสุดและเอกสาร ส่งกลับเมื่อไม่ครบ หรือเลือกผู้อนุมัติเรียงตามจำนวนลำดับของ Workflow
3. รับรายงานจากหัวหน้า ตรวจผ่านหรือส่งกลับพร้อมรายการที่ต้องแก้
4. เมื่อรายงานผ่าน กดปิดเรื่อง ระบบแจ้งประชาชนและผู้ติดตาม

## หัวหน้าทีม
1. สร้างทีม เลือกสมาชิกและตัวแทนทีม หรือมอบหมายบุคลากรคนเดียวได้
2. เปิดคำร้องที่ได้รับมอบหมาย เลือกทีม/ผู้ลงพื้นที่ หากทีมปฏิเสธสามารถจัดใหม่ได้
3. เมื่อทีมขอทรัพยากร แนบเอกสารแล้วกรอกข้อเสนอ งบประมาณ และระยะเวลา ส่งให้เจ้าหน้าที่ตรวจ
4. ถ้าเอกสารถูกคืน ให้แก้ข้อเสนอส่งใหม่ ระบบเก็บฉบับเก่า
5. ตรวจรายงานทีม ส่งกลับแก้ไขหรือส่งต่อเจ้าหน้าที่
6. หากเจ้าหน้าที่ส่งรายงานคืน สามารถคืนทีมแก้ไขหรือชี้แจงและส่งต่ออีกครั้ง

## ทีมลงพื้นที่
ตัวแทนทีมเป็นผู้ทำรายการหลัก สมาชิกคนอื่นเปิดดูงานได้
1. ตรวจรายละเอียดแล้วรับงาน หรือปฏิเสธพร้อมเหตุผล
2. ถ้าต้องใช้ทรัพยากรให้ขอก่อนเริ่มงาน หัวหน้าจะจัดทำข้อเสนอ
3. หากไม่ต้องใช้ทรัพยากร หรืออนุมัติครบแล้ว ให้เริ่มปฏิบัติงาน
4. แนบหลักฐานใหม่ก่อนส่งรายงานแต่ละฉบับ แล้วกรอกข้อเท็จจริง/ผลดำเนินงาน
5. หากไม่ผ่าน ให้อ่านข้อเสนอแนะ แนบหลักฐานใหม่ และส่งรายงานแก้ไข

## ผู้อนุมัติ
ตรวจข้อเสนอและเอกสารในงานที่รออนุมัติของตน บันทึกเหตุผลทุกครั้ง
- อนุมัติ: ส่งลำดับถัดไป หรือให้ทีมเริ่มงานเมื่อครบ
- ไม่อนุมัติ: ยุติคำร้องทั้งเรื่องทันที และยกเลิกงานที่ค้าง

## ผู้ดูแล
- จัดการบัญชี เปิด/ปิดบัญชี และหน่วยงาน
- ตั้งประเภทปัญหา หน่วยงานรับผิดชอบ SLA และช่องข้อมูลเพิ่มเติม
- เผยแพร่ Workflow เวอร์ชันใหม่ จำนวนผู้อนุมัติ 1–5 แล้วนำไปใช้กับประเภทปัญหา
- Workflow รุ่นเก่าของคำร้องที่กำลังดำเนินการไม่เปลี่ยนตาม
- ผู้ดูแลไม่สามารถใช้สิทธิ์ Admin แทนผู้อนุมัติในคำร้องได้

## เมื่อข้อมูลเปลี่ยนระหว่างทำงาน
หากพบข้อความข้อมูลเปลี่ยนแล้ว ให้โหลดรายละเอียดใหม่ ตรวจสถานะล่าสุดก่อนทำรายการอีกครั้ง อย่าส่งซ้ำด้วยเลขเวอร์ชันเดิม
