# หมวดแจ้งปัญหาและไฟล์แนบ

หมวดเริ่มต้น 24 หมวดครอบคลุมงานบริการสาธารณะของเทศบาล เช่น ถนน ทางระบายน้ำ ไฟสาธารณะ ขยะ น้ำเสีย เหตุรำคาญ สัตว์จรจัด สุขาภิบาล อาคาร สวนสาธารณะ การศึกษา สวัสดิการ และอื่น ๆ ในอำนาจหน้าที่เทศบาล

อ้างอิงขอบเขตตาม พ.ร.บ.เทศบาล มาตรา 50–51 และ พ.ร.บ.กำหนดแผนและขั้นตอนการกระจายอำนาจฯ มาตรา 16: https://infocenter.oic.go.th/เทศบาลตำบลจอมพระ%20จังหวัดสุรินทร์/topic-detail.php?conid=5468305
ต้องตรวจประเภทเทศบาล เขตพื้นที่ เจ้าของทรัพย์สิน หน่วยงานที่รับผิดชอบ และอำนาจตามกฎหมายเฉพาะก่อนปฏิบัติงาน หมวดในระบบไม่ใช่การขยายอำนาจเทศบาล ผู้ดูแลต้องตั้งหน่วยงานรับผิดชอบ/SLA ให้ตรงพื้นที่จริง

Migration V10 ปิดหมวดขอรถกระเช้าและเพิ่มหมวดใหม่ ไม่ลบคำร้องหรือไฟล์เดิม การติดตั้งใหม่ใช้รายการเดียวกันจาก MunicipalCategories

## ไฟล์แนบ

- ต้องแนบหลักฐานอย่างน้อย 1 ไฟล์ การบันทึกคำร้องและไฟล์อยู่ใน transaction เดียวกัน ถ้าไฟล์ไม่ผ่านจะยกเลิกการบันทึกทั้งหมด
- PNG, JPEG, PDF และวิดีโอ MP4, MOV (QuickTime), WebM; ตรวจลายเซ็นชนิดไฟล์ฝั่ง backend และตรวจด้วย ClamAV ก่อนบันทึก
- ไฟล์ละไม่เกิน **100 MB**; ไฟล์ของผู้แจ้งรวมไม่เกิน **300 MB** ต่อคำร้อง; ไฟล์ทั้งคำร้องรวมหลักฐานเจ้าหน้าที่ไม่เกิน 1 GB
- ประชาชนถ่ายวิดีโอในระบบได้ครั้งละไม่เกิน 60 วินาที (ราว 2 Mbps ≈ 15 MB) ระบบหยุดเองเมื่อครบเวลา และตรวจขนาดในเครื่องก่อนอัปโหลด บอกทันทีว่าเกินเท่าไร
- แนบทีละไฟล์ผ่าน API; ไม่ต้องรวมไฟล์เป็นก้อนเดียว การถอดไฟล์จากรายการก่อนส่งทำให้พื้นที่ที่เลือกกลับมาใช้งานได้
- Backend ล็อกแถวคำร้องก่อนนับโควตา ป้องกันหลายคำขออัปโหลดพร้อมกันทะลุเพดาน
- รับและสแกนไฟล์แบบสตรีม ไม่อ่านไฟล์ทั้งหมดเข้า Java heap; ต้องมีพื้นที่ดิสก์สำหรับ multipart ชั่วคราวและไฟล์ปลายทาง
- Reverse proxy รับ multipart ได้ 310 MB เผื่อ metadata, timeout 600 วินาที; Spring รับไฟล์ละ 100 MB คำขอละ 310 MB; backend ตรวจตัวไฟล์และผลรวมซ้ำ
- ClamAV ตั้ง StreamMaxLength/MaxFileSize 1024M, MaxScanSize 2048M, MaxScanTime 600000 ms และ AlertExceedsMax=yes; ถ้าสแกนไม่ผ่านหรือเกินข้อจำกัดจะไม่รับไฟล์
- ดาวน์โหลดผ่านสิทธิ์คำร้องเดิม ไม่เปิดไฟล์สาธารณะและไม่เพิ่มการเล่นไฟล์ inline
