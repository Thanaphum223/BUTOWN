ระบบขอสิทธิ์ตำแหน่งผ่าน Browser และให้ผู้แจ้งยืนยันตำแหน่งก่อนเข้าสู่รายละเอียดปัญหา

# GPS และฟอร์มแจ้งปัญหา 2 ขั้น

- GeoProvider ขอ Browser Geolocation เมื่อเข้าเว็บครั้งแรกในแต่ละการเปิดหน้าเว็บ แชร์ผลในหน่วยความจำให้ทุกหน้าที่รับพิกัด ไม่เก็บพิกัดใน localStorage และไม่ใช้ watchPosition
- Browser เป็นผู้ให้/ปฏิเสธสิทธิ์ แอปไม่สามารถข้ามสิทธิ์ของ Browser/ระบบปฏิบัติการได้ ต้องใช้ HTTPS เมื่อขึ้นเซิร์ฟเวอร์จริง (localhost ใช้ทดสอบได้)
- หน้าแรกและหน้าแจ้งปัญหาเติมตำแหน่งจาก GPS เดียวกัน หากไม่อนุญาต ใช้หมุด/ที่อยู่ที่กรอกเองได้
- ขั้นที่ 1 ระบุสถานที่ ตรวจ GPS และยืนยันตำแหน่ง ขั้นที่ 2 เลือกประเภทปัญหา กรอกรายละเอียด/ติดต่อ และแนบหลักฐานอย่างน้อย 1 ไฟล์ จากนั้นแสดงใบรับเรื่องเมื่อบันทึกคำร้องและไฟล์สำเร็จ
- ช่องสถานที่ใช้ชื่อสถานที่/ที่อยู่จากบริการ Reverse Geocoding ที่ตั้งไว้ โดยไม่ใส่เลขพิกัดซ้ำกับส่วน GPS หากค้นหาไม่พบหรือบริการไม่พร้อม จะให้กรอกสถานที่หรือจุดสังเกตเองและมีปุ่มค้นหาที่อยู่อีกครั้ง ไม่เขียนทับข้อความที่ผู้ใช้แก้เองหรือใช้ผลจากหมุดเก่า
- GEOCODING_BASE_URL ต้องเป็นบริการ Nominatim-compatible ที่หน่วยงานอนุมัติหรือดูแลเอง ค่าเริ่มต้นว่าง ไม่มีการส่ง GPS ไปบริการค้นหาที่อยู่ภายนอกโดยปริยาย
- เมื่อยังไม่ตั้งบริการค้นหาชื่อสถานที่ จะแจ้งให้ปักหมุดหรือกรอกที่อยู่เอง การค้นหาด้วยตัวเลข latitude,longitude ทำงานได้โดยไม่ใช้บริการภายนอก
- Backend จำกัดบริการค้นหาไม่เกินประมาณ 1 request/วินาที/instance และ Cache 200 คำขอ ไม่ใช่ autocomplete
- contactName/contactPhone เป็นข้อมูล Private เก็บในคำร้อง ไม่ส่งใน nearby API; เจ้าหน้าที่ที่มีสิทธิ์ในคำร้องจึงจะเห็น
- หมวดเริ่มต้น 8 ประเภทเป็นการตั้งค่าระบบ ผู้ดูแลต้องตรวจหน่วยงานรับผิดชอบ/SLA ก่อนใช้งานจริง โดยเฉพาะหมวดเหตุฉุกเฉิน การส่งคำร้องไม่ได้เรียกหน่วยฉุกเฉิน

## Nominatim สำหรับเว็บทดสอบ

เจ้าของแอปต้องตัดสินใจและรับทราบ [Nominatim Usage Policy](https://operations.osmfoundation.org/policies/nominatim/) ก่อนเปิดใช้บริการสาธารณะ ตั้ง `GEOCODING_BASE_URL=https://nominatim.openstreetmap.org` ใน `.env` ฝั่งเซิร์ฟเวอร์ แล้วสร้าง backend container ใหม่เพื่ออ่านค่า (ไม่ต้องมี API key) ค่าเริ่มต้นของโครงการยังว่างอยู่

- ระบบส่งเฉพาะพิกัดจุดที่เลือกหรือคำค้นสถานที่ ไม่ส่งข้อมูลบัญชี ผู้แจ้ง เนื้อหาคำร้อง หรือไฟล์แนบไปบริการนี้ ไม่ควรใส่ข้อมูลส่วนบุคคลหรือข้อมูลลับในคำค้น
- จำกัดรวมทั้งเว็บไม่เกิน 1 คำขอต่อวินาที โดยใช้ backend instance เดียว; proxy ปัจจุบันเว้นอย่างน้อย 1.1 วินาที และ cache 200 คำขอ ผู้ใช้หลายคนจะแชร์เพดานเดียวกัน
- ค้นหาเมื่อผู้ใช้กดค้นหาหรือเลือกจุด ไม่ใช้ autocomplete, bulk lookup, polling หรือตารางพิกัด; หากเพิ่ม backend หลาย instance ต้องใช้ตัวจำกัดร่วมกันหรือเปลี่ยนเป็นบริการที่รองรับปริมาณงาน
- ระบุ User-Agent ของ TownTrack และ attribution ของ OpenStreetMap; เปลี่ยนบริการผ่าน ENV ได้โดยไม่แก้โค้ด
- ผล Reverse Geocoding เป็นที่อยู่ของวัตถุที่เหมาะสมใกล้จุดที่เลือก ไม่รับประกันเลขที่/ชื่อถนนตรงจุดทุกครั้ง ผู้แจ้งตรวจและแก้ไขก่อนยืนยันตำแหน่งได้ ([คู่มือ Reverse API](https://nominatim.org/release-docs/latest/api/Reverse/))
