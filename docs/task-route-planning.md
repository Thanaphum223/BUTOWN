# Task route planning — retired

Removed from TownTrack on 6 November 2026 at the project owner's request. The route menus, screens, APIs, optimization and OSRM integration are no longer available.

Use the ordinary complaint queue: the central officer assigns the department/head, and the head assigns each complaint to their field team. Existing work continues through acceptance, starting work, resource requests, reporting, review and closure.

Migration V26 releases route reservations and cancels only unstarted DRAFT/PROPOSED rounds. Historical route records and dispatched work remain in the database; complaints, work orders, evidence and audit history are preserved. V25 remains unchanged for Flyway upgrade compatibility.
