# สถานะการส่งมอบ TownTrack

วันที่ทดสอบ: 29 ตุลาคม 2026 (Asia/Bangkok)

## ทำงานแล้ว
- Frontend ภาษาไทย รองรับ Desktop/Mobile บน React/TypeScript/Vite/Ant Design ปรับ UI ตาม municipal-web: หน้าประชาชนแผนที่/การ์ด/เมนูล่าง และหน้าบุคลากรคิวงานคู่รายละเอียด
- Backend Java 21 / Spring Boot 3.5.16 / Spring Security ใช้ API และ PostgreSQL/PostGIS จริง
- Flyway 11.20.3 และ Migration 9 ชุด
- สมัครประชาชนและ Session Login, CSRF, BCrypt, เปลี่ยนรหัสผ่านและยกเลิก Session เดิม
- รับ/ปฏิเสธคำร้อง ส่งหัวหน้า จัดทีม ตัวแทนทีมรับ/ปฏิเสธ และมอบหมายใหม่
- คำขอทรัพยากรและฉบับแก้ไข ตรวจเอกสาร อนุมัติเรียงลำดับ 1–5 คน
- ไม่อนุมัติที่ลำดับใดให้ยุติทั้งคำร้องและยกเลิกงานที่ค้าง
- รายงานหลายฉบับ หลักฐานส่วนตัว หัวหน้าตรวจ เจ้าหน้าที่ตรวจและส่งกลับ ปิดเรื่อง
- ค้นหาเคสซ้ำภายใน 100 เมตร และติดตามข้อมูลสรุปโดยไม่เปิดเผยข้อมูลผู้แจ้ง
- ตรวจสิทธิ์ระดับเทศบาล หน่วยงาน ผู้รับผิดชอบ และตัวแทนทีม
- ล็อกคำร้องใน Transaction และตรวจ version กันรายการซ้ำ/ข้อมูลชน
- Audit เพิ่มอย่างเดียว; Trigger ป้องกันแก้/ลบประวัติผ่าน SQL ปกติ
- ตั้งผู้ใช้ หน่วยงาน ประเภท แบบฟอร์มข้อความ SLA และจำนวนลำดับอนุมัติแบบมีเวอร์ชัน
- ค้นหา/แบ่งหน้าคำร้องจาก Server และสถิติรวมในขอบเขตสิทธิ์
- แจ้งเตือนในระบบ และเตือน SLA เมื่อเกินกำหนด
- โค้ด LINE LIFF Login ตรวจ Token ฝั่ง Server และคิวส่งข้อความพร้อม Retry; ปิดจนกว่าจะกำหนดค่าจริง
- แยก GovCenterPort และรหัสอ้างอิง Integration โดยยังไม่เชื่อมระบบกลาง

- ขอ GPS เมื่อเข้าเว็บครั้งแรกและแชร์พิกัดเติมทุกหน้าที่รับตำแหน่ง
- ฟอร์มแจ้งปัญหา 3 ขั้นตามภาพ พร้อมข้อมูลติดต่อ Private และใบรับเรื่องจริง
- บริการค้นหาชื่อสถานที่/Reverse Geocode ตั้ง GEOCODING_BASE_URL ได้ (ค่าเริ่มต้นยังไม่เปิดบริการภายนอก)

## ต้องดำเนินการก่อนเปิดบริการจริง
1. ติดตั้งและทดสอบบนเซิร์ฟเวอร์ปลายทาง รวม Reverse Proxy HTTPS, Certificate, Cookie และ Firewall
2. ตั้ง ClamAV และทดสอบตรวจมัลแวร์จริง โหมดในเครื่องขณะพัฒนาเปิด DEV_UNSCANNED_FILES เพื่อทดสอบ API/ไฟล์โดยไม่ใช้ Antivirus
3. ตั้ง LINE Channel/LIFF/OA และทดสอบกับบัญชีจริง ยังไม่มีการส่งข้อความจริงจากสภาพแวดล้อมนี้
4. ตั้งชื่อเทศบาล หน่วยงาน บัญชีบุคลากร และนโยบายข้อมูลจริง เปลี่ยน/ไม่ใช้บัญชี Demo
5. กำหนดการสำรองเข้ารหัสนอกเครื่อง RPO/RTO การเก็บ Log และทดสอบกู้คืนบนปลายทาง
6. ทดสอบรับมอบกับเจ้าหน้าที่เทศบาลตามสถานการณ์จริง และประเมินโหลดตามจำนวนผู้ใช้เป้าหมาย ซึ่งยังไม่ได้รับข้อมูล
7. Docker/Compose และ GitHub CI จัดไฟล์ให้แล้ว แต่ยังไม่ได้รันในสภาพแวดล้อมเหล่านั้น เพราะเครื่องนี้ไม่มี Docker และยังไม่ได้ส่งโครงการขึ้น GitHub

## ขอบเขตที่ระบุไว้ชัดเจน
- รองรับ Workflow ตาม Flow ที่ตกลงและปรับจำนวนผู้อนุมัติ ไม่ใช่ตัววาดเส้นทาง BPMN อิสระ
- ข้อมูลเพิ่มเติมของแบบฟอร์มเป็นข้อความ ไม่ใช่ชุด Field ทุกชนิด
- ยังไม่มี MFA, การมอบอำนาจอนุมัติชั่วคราว, Digital Signature, งาน Offline หรือระบบเบิกจ่ายจริง

- Frontend Build มีคำเตือนขนาด Bundle หลัก (~436 KB gzip) ต้องประเมินความเร็วบนเครือข่ายจริง
- GovCenter ยังไม่เชื่อมตามขอบเขตที่ผู้ใช้กำหนด
