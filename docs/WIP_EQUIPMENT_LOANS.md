# ใบยืมครุภัณฑ์ และแบบ 3/แบบ 4

สถานะ: **โค้ดครบแล้ว แต่ต้องให้เจ้าของยืนยันก่อน push ขึ้น origin** (push ขึ้น origin = deploy เว็บจริง) ตอนนี้อยู่บน BUTOWN เท่านั้น

ที่มา
- ระเบียบกระทรวงการคลังว่าด้วยการจัดซื้อจัดจ้างและการบริหารพัสดุภาครัฐ พ.ศ. 2560 ข้อ 208(2), 209, 211
- ระเบียบกระทรวงมหาดไทยว่าด้วยการใช้และรักษารถยนต์ของ อปท. พ.ศ. 2548 แก้ไขเพิ่มเติม (ฉบับที่ 2) พ.ศ. 2563 (แบบ 3/แบบ 4)

รายละเอียด endpoint อยู่ใน `docs/API.md` หัวข้อ "ครุภัณฑ์ยืมและยานพาหนะ"

## สิ่งที่ทำแล้ว

- `V38__equipment_loans.sql`: ทะเบียนคุมการยืม (`equipment_loan`), `app_user.loan_approver`, `resource_request.loan_due_on`
- `V39__vehicle_use.sql`
  - ยานพาหนะ = ครุภัณฑ์ที่มี `stock_item.vehicle_plate` จึงใช้กติกาใบยืม การอนุมัติ และการรับคืนเดียวกับครุภัณฑ์
  - `resource_request.vehicle_use`: เก็บข้อมูลแบบ 3
  - `vehicle_trip`: บันทึกการใช้รถตามแบบ 4
  - `municipality.vehicle_local_exempt`: สวิตช์ยกเว้นแบบ 3 เมื่อใช้รถภายในเขต
- Backend
  - `Workflow`: REQUEST_RESOURCE ตรวจ `loanDueOn` และ `vehicleUse` / START เปิดใบยืมและบันทึกเลขไมล์ออก / REPORT รับสภาพของที่คืนและเลขไมล์กลับ / UNDO_START ปิดใบยืมเป็น CANCELLED และยกเลิกเที่ยวรถ
  - `EquipmentLoans`: ทะเบียนยืม รับคืน แจ้งเตือนเกินกำหนด 08:00 มอบอำนาจผู้อนุมัติ บันทึกการใช้รถ และตั้งค่ายกเว้นแบบ 3
  - `Vehicles`: ตรวจแบบ 3 และจัดการเที่ยวรถตามแบบ 4
  - `ComplaintRetention`: ลบคำร้องแล้วทะเบียนยืมและบันทึกการใช้รถยังอยู่ แต่ตัดลิงก์ไปยังคำร้อง
- Frontend
  - `Detail`: วันส่งคืนครุภัณฑ์ ฟอร์มแบบ 3 และเลขไมล์ตอนเริ่มงานและตอนส่งรายงาน
  - `StockFields`: สภาพครุภัณฑ์ที่คืน และ `VehicleOdometers`
  - `Inventory`: ทะเบียนยืม แบบ 4 ทะเบียนรถตอนเพิ่มครุภัณฑ์ สวิตช์มอบอำนาจ และสวิตช์ยกเว้นแบบ 3
  - `ResourceReview`: ผู้อนุมัติเห็นวันส่งคืนและข้อมูลแบบ 3
- Tests
  - `StockAndSlaIntegrationTest`: ครอบคลุมวันส่งคืน การรับคืน 3 สภาพ การยกเลิกเริ่มงาน การแจ้งเตือนเกินกำหนด แบบ 3 และเลขไมล์แบบ 4
  - `ComplaintRetentionIntegrationTest`: ตรวจว่าทะเบียนยังอยู่หลังลบคำร้อง

## ข้อสันนิษฐานที่ควรให้เจ้าของตรวจ

- แบบ 3 ใช้สายอนุมัติเดิมของคำขอใช้ทรัพยากร ข้อความต้นทางไม่ได้ระบุผู้อนุมัติไว้ ส่วนสายอนุมัติของรถใช้เงื่อนไขเดียวกับครุภัณฑ์ คือผู้อนุมัติลำดับสุดท้ายต้องเป็น MAYOR หรือ loan_approver
- การยกเว้นแบบ 3 เมื่อใช้รถภายในเขตปิดไว้ตั้งต้น แม้ยกเว้นแล้วก็ยังต้องบันทึกเลขไมล์ตามแบบ 4

## ก่อน push ขึ้น origin (deploy)

1. แจ้งเจ้าของก่อน deploy ว่าคำขอที่มีครุภัณฑ์หรือรถจะ**อนุมัติลำดับสุดท้ายไม่ได้** จนกว่าจะตั้ง gov_role `MAYOR` หรือเปิด "ผู้รับมอบอำนาจอนุมัติยืมครุภัณฑ์" ให้ผู้อนุมัติอย่างน้อย 1 คน (หน้าคลัง > กำหนดผู้ดูแลคลัง)
2. ครุภัณฑ์ที่เป็นรถอยู่แล้วต้องใส่ทะเบียนรถ: หน้าคลัง > ปุ่ม "ทะเบียนรถ" ของรายการนั้น ไม่อย่างนั้นระบบจะไม่ขอแบบ 3/แบบ 4
3. ทำตาม checklist ใน skill `towntrack-ship`
