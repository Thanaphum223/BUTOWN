# หน้าจอ TownTrack

## ประชาชน
- โทนเขียวและขาว รองรับคอมพิวเตอร์และโทรศัพท์ มีเมนูชุมชน แจ้งปัญหา ติดตามเรื่อง การแจ้งเตือน และบัญชี
- แจ้งปัญหา 2 ขั้น: จุดเกิดเหตุ และรายละเอียดปัญหา
- ค้นหาสถานที่ เลือกหมุด ยืนยันตำแหน่ง และค้นหาเคสใกล้เคียงอัตโนมัติในรัศมี 100 เมตร
- ประเภทปัญหาค้นหาและเลือกหน้าได้ หน้าละ 6 หมวด
- ต้องแนบหลักฐานอย่างน้อย 1 ไฟล์ก่อนส่งคำร้อง รวมไม่เกิน 1 GB

## บุคลากร
- เมนูด้านข้าง สถิติงาน คิวคำร้อง และรายละเอียดพร้อมปุ่มดำเนินการตามสิทธิ์
- จอเล็กแสดงคิวและรายละเอียดในแนวตั้ง
- ตรวจสิทธิ์และขั้นตอนงานที่ backend
