# การปรับ UI ตาม municipal-web

อ้างอิงไฟล์ปัจจุบันใน D:\municipal-web (ไม่ใช้โฟลเดอร์ backup) และปรับในโครงการ D:\TownTrack

## หน้าประชาชน
- ใช้หัวเว็บเทศบาล โทนเขียว/ขาว/พื้นเขียวอ่อน การ์ดขอบมน และเมนูด้านล่าง
- หน้าแรกมีสถิติคำร้องของผู้ใช้ แผนที่ และการ์ดเคสใกล้เคียง
- ค้นหาจาก GPS ที่ผู้ใช้กดอนุญาต หรือแตะเลือกตำแหน่งเอง แล้วค้นหาประเภทเดียวกันภายใน 100 เมตร
- การ์ดเคสแสดงเฉพาะข้อมูลสรุปจาก API เดิม และติดตามได้จริง ไม่แสดงรายละเอียดส่วนตัวหรือรูปภายใน
- เพิ่มปุ่มขยาย/ย่อขนาดตัวอักษร

## หน้าบุคลากร
- Sidebar เขียวเข้ม สถิติด้านบน คิวงานด้านซ้าย และรายละเอียดพร้อมปุ่มดำเนินการด้านขวา
- เลือกคำร้องแล้วทำงานได้ในหน้าเดียว ขอบเขตสิทธิ์ยังตรวจที่ Backend เดิม
- จอเล็กจัดคิวและรายละเอียดเป็นแนวตั้ง
- คำเตือนงานเกินกำหนดมาจากสถิติจริง

## ขอบเขตการเปลี่ยน
ปรับเฉพาะ Frontend และ Browser Tests ไม่มีการเปลี่ยน Backend, API contract หรือโครงสร้างฐานข้อมูล ไม่ใช้ข้อมูลจำลองใน municipal-web แทนข้อมูลจริง และไม่เพิ่มปุ่มสลับบทบาทจำลองลงระบบ

## ตรวจสอบ
TypeScript และ Production Build ผ่าน Browser Tests ทั้ง 8 กรณีผ่าน รวม Flow จบงาน การไม่อนุมัติทรัพยากร และการค้นหา/ติดตามเคสจากแผนที่โดยไม่เปิดเผยข้อมูลส่วนตัว
