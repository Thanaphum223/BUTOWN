# หน้าจอ TownTrack

## ประชาชน
- โทนเขียวและขาว รองรับคอมพิวเตอร์และโทรศัพท์ มีเมนูชุมชน แจ้งปัญหา ติดตามเรื่อง การแจ้งเตือน และบัญชี
- แจ้งปัญหา 2 ขั้น: จุดเกิดเหตุ และรายละเอียดปัญหา
- ค้นหาสถานที่ เลือกหมุด ยืนยันตำแหน่ง และค้นหาเคสใกล้เคียงอัตโนมัติในรัศมี 100 เมตร
- ประเภทปัญหาค้นหาและเลือกหน้าได้ หน้าละ 6 หมวด
- เลือกอาการจากปุ่มได้หลายข้อ หัวข้อและรายละเอียดอื่น ๆ ไม่บังคับ
- ต้องแนบหลักฐานอย่างน้อย 1 ไฟล์ก่อนส่งคำร้อง ไฟล์ละไม่เกิน 100 MB รวมไม่เกิน 300 MB หรือถ่ายวิดีโอในระบบไม่เกิน 60 วินาที
- มีข้อความ PDPA ใกล้ปุ่มถ่ายภาพ และแจ้งว่าข้อมูลติดต่อผู้แจ้งไม่เผยแพร่
- ใช้ธีม Gov สีเดียว ไม่มีโหมดมืด

## บุคลากร
- เมนูด้านข้าง สถิติงาน คิวคำร้อง และรายละเอียดพร้อมปุ่มดำเนินการตามสิทธิ์
- จอเล็กแสดงคิวและรายละเอียดในแนวตั้ง
- ตรวจสิทธิ์และขั้นตอนงานที่ backend
- หัวหน้าเห็นงานค้างและงานที่ผู้ลงพื้นที่กำลังทำตอนจ่ายงาน; เจ้าหน้าที่ได้ผู้อนุมัติที่เลือกบ่อยเป็นค่าเริ่มต้น; ผู้อนุมัติเลือกเหตุผลจากปุ่มได้
- เมนูคลังวัสดุ: ยอดคงเหลือ ของที่อยู่หน้างาน และประวัติเข้า-ออก
- รายละเอียดคำร้องแสดงกำหนดแก้ไขเสร็จ กำหนดแจ้งความคืบหน้า และคำขอขยายเวลา
